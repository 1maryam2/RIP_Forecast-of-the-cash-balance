# Разработка Интернет Приложений(РИП)
## Лабораторная работа №8: Межсервисное взаимодействие, асинхронность, внедрение Real-time web
__Цель работы:__  Межсервисное взаимодействие, асинхронность, внедрение Real-time web

__Порядок показа:__ вызвать через insomnia GET списка заявок, затем http-метод асинхронного сервиса (в insomnia и отдельно кнопкой в интерфейсе), показать что в GET списка заявок появился результат с задержкой, потом вызвать новый метод основного сервиса с ключом, чтобы изменить результат. Сделать скриншоты всех изменений в РПЗ по 2025 году, скриншоты TestVKR и объема файла РПЗ.

__Контрольные вопросы:__ grpc, асинхронность, веб-сервис

__Задание:__ Создание асинхронного сервиса для отложенного действия (вычисление, моделирование, оплата и тд), одобрение заявок модератором
